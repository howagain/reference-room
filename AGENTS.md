# Reference Room

Canonical purpose: `automate-friday-wiki/wiki/concepts/AgencyMoodboard.md` in the
parent Automate Friday repository. Build an open-source white-label agency
mood-board portal with Pinterest imports, comments, portable agent prompts,
HTML swipe review, and persistent client dashboards.

Use npm. Keep client/agency authorization on every API and file read. Imported
HTML always renders in a sandbox without same-origin privileges. Do not invent
AI analysis: copy prompts out and import the agent's actual response.
